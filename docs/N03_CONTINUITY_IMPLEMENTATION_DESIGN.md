## Smallest credible enforcement choices

**Vetted engine patch** is the shortest ownership path: add a fail-closed continuity guard to aria2's actual response processing, before opening/modifying retained storage or accepting body bytes. Persist a versioned strong representation record durably before first body consumption. It contains exact effective resource identity, strong ETag, total representation length, identity encoding and request/attempt binding; Last-Modified or weak/missing ETag must not authorize partial reuse. Apply the guard to every HTTP response, including redirects and internally recreated commands. Retained-control loading itself must not cause a write before this decision. Metadata writes require flush/atomic replace and explicit crash ordering. Fresh one-shot transfers may complete without a resumable validator, but interrupted ones then cannot reuse bytes. A new filename remains the explicit safe restart path.

A **managed streaming gateway** can own response headers/body but is not just a URL rewrite. Prefer a vetted HTTP server/framework to a new ad hoc HTTP parser. It must run under engine lifetime, bind only loopback, authenticate capability routes with bounded requests, expose no arbitrary URL relay, and map opaque per-attempt routes to authoritative exact sources. No origin URL/secret goes in the route. All add/input-file/recovery sources must become gateway routes before the engine can run. Restored route mappings need durable endpoint ownership; an old surviving direct-source engine must be preserved/refused, never silently adopted as guarded. An engine surviving a gateway crash must only fail, never fall back to its original URL. Runtime dependency, self-contained/MSIX packaging and orphan ownership require validation.

For both choices, a nonzero single Range request must send If-Match with the stored strong ETag. Before forwarding any response/body, require 206, identical strong ETag/effective resource/identity encoding, exactly matching Content-Range start and known total, valid end and Content-Length relationship. Reject weak/missing/changed validators, malformed or mismatched ranges, 200/412/416, encoded variants and resource changes. No redirect response reaches aria2 as a direct-source escape. Do not trust ETag alone across differing resources.

**Preservation makes gateway-only filtering insufficient:** aria2 can save/delete/rewrite its control file on failure regardless of whether origin body bytes were forwarded. An attempt must operate on private staged payload/control copies, leaving the retained pair immutable until successful validated completion. Publication needs a durable transaction/manifest for the two files, collision protection and crash recovery. Pausing an existing original-path GID cannot be fixed by polling or by opportunistically copying files while aria2 holds them; storage ownership must be designed from first Add. Preserve manual attempt lineage and uncertain dispatch semantics while routing staged work. This change touches coordinator destination semantics, engine session restoration and migration/runtime ownership together.

## DNS and redirects

The gateway/patch must enforce the app's target policy at every actual connection and redirect, not only a parser or preflight DNS lookup. Resolve and select permitted public addresses with connection-time pinning, verify TLS against the original hostname, reject private/loopback/link-local/mapped literals and DNS rebinding, limit redirect count, reject HTTPS downgrade and unexpected effective-resource changes during reuse. Disable automatic redirects until each hop is evaluated. A preflight resolve followed by aria2's independent resolution is a race and does not close the existing browser DNS/redirect gate. Controlled loopback test origins need a fixture-only explicit policy; normal production must not inherit that exception.

## Required proof before enabling

1. First-response metadata durable before body; kill at metadata/first-byte/control-load/publication boundaries and restart with immutable retained files.
2. Genuine nonzero Range/206 with stable strong validator and final SHA passes through Retry, same-GID Resume, internal reconnect and startup/recovery. No direct-origin bypass.
3. Changed/missing/weak validator, ETag-only metadata from legacy downloads, invalid range/length/encoding, 200/412/416 and changed effective resource produce truthful Failed with both retained files byte-identical.
4. DNS/redirect/TLS policy exercises actual chosen sockets, including rebinding, downgrade and private redirect. Legacy direct-engine adoption is denied/preserved without termination or silent new transfer.
5. Crash publication, queue limits, manual cancellation, pause/retry lineage, lost engine reply, orphan adoption and clean-machine/MSIX packaging regressions pass.

No pure validator helper or aria2 option provides these ownership guarantees. The current gated gateway integration implements an actual response/body boundary and passes controlled N01/N02/N03 without blanket continuation denial. The default direct-path gate remains failing and application cutover is unfinished; this document is not release approval.
