### Independent review failure and diagnostic correction

The parent's restricted-context run `artifacts/browser-wp0/review-20261011-a/results.json` failed private-pipe with OperationCanceledException after the 15-second parent deadline; the other three spikes passed. A restricted reproduction (`diagnose-20261011-restricted`) reproduced that failure. The harness had discarded child stderr and waited only for the server connection, obscuring an early client failure.

The corrected harness races connection against child exit, records fixed stage/error tokens without SID/endpoint/payload data, retains bounded waits, and terminates only its own surviving child on failure. It does not retry, relax the ACL, or convert a failure into a pass. `diagnose-20261011-restricted-b/pipe-diagnostics.json` records **waiting-for-client**, child exit **2**, **UnauthorizedAccessException** at **connecting**, after **117 ms**. The result remains failed. The corresponding ordinary user-context run `diagnose-20261011-elevated-b/pipe-diagnostics.json` records complete, child exit 0, request/reply and identity checks passed after 127 ms. This supports an execution-context access restriction rather than an observed framing race; exact restricted-token policy was not inspected. The pipe proof passes only in the tested ordinary user context, not universally. Cross-user and remote acceptance limits remain open.

Independent reruns after the harness correction confirmed the distinction: `review-20261011-b` failed promptly in the restricted context with the child's `UnauthorizedAccessException`, while `review-20261011-c` passed all 22 checks in the ordinary user context. The latter pipe exchange completed in 124 ms with child exit 0.

## Decisions for subsequent packages

1. Keep native host separate from GUI activation, with exact bounded binary framing and caller validation. A successful browser hello proves launch/authorization for this development fixture; it does not prove the GUI is ready. Treat extension origin and pipe peer identity as separate checks. Current-user identity alone does not defend against malicious same-user software. Installer-selected trusted paths and endpoint inputs must be explicit.
2. Use a private local named pipe with explicit ACL, remote rejection and first-instance protection. Derive endpoint identity from current SID, channel, installation, package model and normalized runtime location. The spike validates differing names, not actual MSIX activation. Verify deployed package identity and trusted executable/token checks before accepting requests.
3. Extend the existing repository transaction boundary to atomically commit receipt and full durable intent. Do not wrap current `DownloadCoordinator.AddAsync` and call its completion durable acceptance: it combines persistence and engine dispatch, returns no durable receipt, and propagates request cancellation into dispatch. Split validation/build-intent, transactional acceptance and independent dispatch lifetime. Freeze authoritative folder/preferences at acceptance; existing PreferencesViewModel swallows load failures, so a completed load task is not a reliable readiness signal.
4. The real current recovery path maps accepted-but-never-sent fixture work to **Interrupted/Uncertain**, with zero engine adds. It avoids automatic replay but cannot distinguish never-sent from ambiguous engine acceptance. Before Package 2, persist a dispatch phase that supports safe never-sent recovery, or return a truthful recovery-required state and require explicit recovery. Do not claim automatic reliable dispatch from the present schema.
5. Perform attachment marking on a bounded STA worker after durable completion, outside the coordinator gate and polling loop. Persist browser provenance plus marking pending/result so restart can retry. Marking can invoke scanners and alter/delete the file; Open must respect failed or prompt policy. This run's S_FALSE explicitly requires prompt handling. Zone marking is evidence, not a browser-equivalent malware verdict. Define source URL privacy/redaction policy before persisting source into ADS.
